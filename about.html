About

Code by day, a few other things by night.

I'm a front-end developer who ended up building most of my own tools — a life dashboard, a cross-posting app, a grocery platform — because I wanted to see exactly how they'd feel to use.

A bit more

I work mostly in HTML, CSS, and JavaScript, with React for anything that needs to feel like an app rather than a page. I'm particular about semantic structure and keyboard access — not as a checklist, but because it's usually the difference between a page that works and one that only looks like it does.

Outside of that, I split my time between the gym, dance practice, guitar, and a slow-growing Instagram presence. A lot of it eventually turns into a feature request for my own dashboard — which is, admittedly, a strange feedback loop, but it works for me.
